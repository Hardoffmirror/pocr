# PoE Recombinator Simulator

Полнофункциональное приложение для симуляции и расчета вероятностей рекомбинаторов в Path of Exile.

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## 🎮 Возможности

- **Визуальный конструктор предметов** - создавайте предметы с модификаторами через удобный GUI
- **Калькулятор вероятностей** - точный расчет шансов получения желаемых модов
- **Симулятор крафта** - симуляция тысяч попыток рекомбинации
- **Статистика и графики** - детальная визуализация результатов
- **Поддержка всех механик** - эксклюзивные моды, группы модов, тиры, item level и т.д.

## 📋 Требования

- Python 3.8 или выше
- tkinter (обычно входит в стандартную установку Python)
- matplotlib

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Hardoffmirror/pocr.git
cd pocr
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

## 📖 Использование

### 1. Создание предметов

На вкладке **"Настройка предметов"**:
- Создайте два предмета, указав название, класс и item level
- Добавьте модификаторы (префиксы и суффиксы)
- Укажите тир модов, группу и дополнительные параметры
- Отметьте эксклюзивные моды (essence, fossil)

### 2. Расчет вероятностей

На вкладке **"Калькулятор вероятностей"**:
- Просмотрите созданные предметы
- Нажмите "Рассчитать все варианты"
- Изучите все возможные исходы рекомбинации
- Проанализируйте вероятности получения нужных комбинаций

### 3. Симуляция крафта

На вкладке **"Симулятор"**:
- Запустите одну попытку для теста
- Или запустите массовую симуляцию (1000+ попыток)
- Просмотрите детальные результаты
- Изучите распределение исходов

### 4. Статистика

На вкладке **"Статистика"**:
- Просмотрите графики успехов/провалов
- Изучите распределение результатов по модам
- Проанализируйте среднее количество модов

## 🧮 Механики рекомбинаторов

### Основные правила

1. **Совместимость предметов**:
   - Предметы должны быть одного класса
   - Нельзя рекомбинировать corrupted или mirrored предметы
   - Оба предмета должны быть Magic или Rare

2. **Выбор модов**:
   - Из каждой группы модов можно выбрать только один
   - Максимум 3 префикса и 3 суффикса в результате
   - Фрактурированные моды не могут быть выбраны

3. **Эксклюзивные моды**:
   - Только один эксклюзивный мод может быть в результате
   - Нельзя комбинировать предметы с разными эксклюзивными модами

4. **Вероятность успеха**:
   - Зависит от количества выбранных модов
   - Зависит от тиров модов (T1 сложнее)
   - Базовый шанс ~35%, снижается с количеством и качеством модов

### Формулы расчета

**Вероятность выбора конкретных модов**:
```
P = (n1/total) × (n2/(total-1)) × ... × (nk/(total-k+1))
```

**Вероятность успеха крафта**:
```
Success Rate = Base Rate - (Mod Count Penalty) - (Tier Penalty) + (Pool Bonus)
```

Где:
- Base Rate = 35%
- Mod Count Penalty = 5% за каждый мод
- Tier Penalty = 2% × (7 - tier value) за каждый мод
- Pool Bonus = 5% × (6 - total mods) если < 6 модов

## 🎯 Примеры использования

### Пример 1: Создание 3P/3S базы

1. Создайте два предмета с 2 префиксами каждый
2. Рассчитайте вероятность получения 3 префиксов
3. Запустите симуляцию для оценки количества попыток

### Пример 2: Анализ эксклюзивных модов

1. Добавьте essence мод на один предмет
2. Посмотрите, как это влияет на вероятности
3. Сравните с обычными модами

### Пример 3: Оптимизация item level

1. Создайте предметы с разными iLvl
2. Результирующий предмет получит максимальный iLvl
3. Используйте это для улучшения базы

## 🔧 Технические детали

### Модули

- **models.py**: Dataclasses для предметов, модов, результатов
- **calculator.py**: Математические расчеты вероятностей
- **simulator.py**: Симуляция процесса рекомбинации
- **gui.py**: Tkinter GUI с вкладками и визуализацией

### Зависимости

- `tkinter`: Графический интерфейс (встроен в Python)
- `matplotlib`: Графики и визуализация

## 📊 Особенности реализации

1. **Точные расчеты**: Формулы основаны на community research и testing
2. **Все механики**: Поддержка exclusivity, mod groups, fractured mods, influenced items
3. **Визуализация**: Графики распределения результатов
4. **Массовая симуляция**: До 100,000 попыток для точной статистики
5. **Удобный GUI**: Интуитивный интерфейс с вкладками
