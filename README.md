# PoE Recombinator Simulator

Полнофункциональное приложение для симуляции и расчета вероятностей рекомбинаторов в Path of Exile.

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ НОВЫЙ КОМПАКТНЫЙ ИНТЕРФЕЙС (Version 1.3.0)

**Все в одном окне!** Полностью переработанный интерфейс для максимального удобства:

- ⚡ **Единое окно** - никаких вкладок, все функции перед глазами

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Hardoffmirror/pocr.git
cd pocr
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py                    # Новый компактный интерфейс (по умолчанию)
python main.py --old              # Старый интерфейс с вкладками
python main.py --tabs             # Альтернативная команда для старого интерфейса
```

## 📖 Использование

### 🆕 Новый компактный интерфейс (по умолчанию)

**Интерфейс разделен на 3 панели:**

#### 📦 Левая панель - Предметы
1. **Импорт из игры (быстро):**
   - Наведите на предмет в PoE → Ctrl+C
   - Нажмите "📋 Импорт из игры"
   - Вставьте → Готово!

2. **Добавить моды вручную:**
   - Нажмите "➕ Добавить моды"
   - Укажите класс предмета и список модов
   - Формат: `P/S Имя_мода Группа [T1/T2/T3]`

3. **Базовая рекомбинация:**
   - Добавьте оба предмета
   - Нажмите "🎯 Рассчитать рекомбинацию"

#### 🎯 Центральная панель - Желаемый результат
1. **Добавьте желаемые моды:**
   - Нажмите "➕ Префикс" или "➕ Суффикс"
   - Заполните название, группу, тир
   - Отметьте эксклюзивные моды (essence/fossil)

2. **Запустите анализ:**
   - Нажмите "🎲 АНАЛИЗ"
   - Получите детальный пошаговый план
   - Изучите рекомендации по стратегии

#### 💰 Правая панель - Результаты
- **Вероятность успеха** - визуальный прогресс-бар
- **Количество попыток** - среднее и рекомендуемое
- **Тип стратегии** - базовая/exclusive/NNN
- **Ресурсы** - детальный список необходимых материалов
- **Советы и предупреждения** - важные замечания

### 📑 Старый интерфейс с вкладками

Запустите с флагом `--old` для доступа к расширенному интерфейсу:

- **Вкладка 1: Настройка** - создание предметов
- **Вкладка 2: Калькулятор** - расчет вероятностей
- **Вкладка 3: Симулятор** - массовая симуляция
- **Вкладка 4: Статистика** - графики и анализ
- **Вкладка 5: Гайд** - полное руководство
- **Вкладка 6: Помощник** - интеллектуальный советник

### 4. Статистика

На вкладке **"Статистика"**:
- Просмотрите графики успехов/провалов
- Изучите распределение результатов по модам
- Проанализируйте среднее количество модов

### 5. Гайд по механикам

На вкладке **"Гайд"**:
- Полное объяснение механик рекомбинаторов
- Таблицы вероятностей и формулы расчета
- Техники с эксклюзивными модами
- Информация о NNN (Non-Native Natural) модах
- Продвинутые стратегии крафта
- Практические примеры (оружие, доспехи)
- Советы и предостережения

### 6. 🎯 Помощник крафта (РЕКОМЕНДУЕТСЯ!)

На вкладке **"🎯 Помощник крафта"**:

**Как использовать:**
1. Добавьте желаемые префиксы (макс 3)
2. Добавьте желаемые суффиксы (макс 3)
3. Нажмите "Проанализировать"

**Что вы получите:**
- ✅ Проверку возможности получения такой комбинации
- 📊 Точную вероятность успеха
- 🎲 Среднее количество попыток
- 📋 Пошаговый план крафта
- 💰 Расчет необходимых ресурсов
- 💡 Полезные советы и предостережения
- 🔍 Рекомендацию оптимальной стратегии (базовая/exclusive/NNN)

**Примеры:**
- Хотите 3 физ мода на оружие? → Базовая рекомбинация, ~3 попытки
- Хотите 5 модов с essence? → Стратегия с эксклюзивными модами, ~6 попыток
- Пытаетесь получить 4 префикса? → Невозможно, получите предупреждение

## 🧮 Механики рекомбинаторов

### Основные правила

1. **Совместимость предметов**:
   - Предметы должны быть одного класса
   - Нельзя рекомбинировать corrupted или mirrored предметы
   - Оба предмета должны быть Magic или Rare

2. **Выбор модов**:
   - Из каждой группы модов можно выбрать только один
   - Максимум 3 префикса и 3 суффикса в результате
   - Фрактурированные моды не могут быть выбраны

3. **Эксклюзивные моды**:
   - Только один эксклюзивный мод может быть в результате
   - Нельзя комбинировать предметы с разными эксклюзивными модами

4. **Вероятность успеха**:
   - Зависит от количества выбранных модов
   - Зависит от тиров модов (T1 сложнее)
   - Базовый шанс ~35%, снижается с количеством и качеством модов

### Формулы расчета

**Вероятность выбора конкретных модов**:
```
P = (n1/total) × (n2/(total-1)) × ... × (nk/(total-k+1))
```

**Вероятность успеха крафта**:
```
Success Rate = Base Rate - (Mod Count Penalty) - (Tier Penalty) + (Pool Bonus)
```

Где:
- Base Rate = 35%
- Mod Count Penalty = 5% за каждый мод
- Tier Penalty = 2% × (7 - tier value) за каждый мод
- Pool Bonus = 5% × (6 - total mods) если < 6 модов

## 🎯 Примеры использования

### Пример 1: Создание 3P/3S базы

1. Создайте два предмета с 2 префиксами каждый
2. Рассчитайте вероятность получения 3 префиксов
3. Запустите симуляцию для оценки количества попыток

### Пример 2: Анализ эксклюзивных модов

1. Добавьте essence мод на один предмет
2. Посмотрите, как это влияет на вероятности
3. Сравните с обычными модами

### Пример 3: Оптимизация item level

1. Создайте предметы с разными iLvl
2. Результирующий предмет получит максимальный iLvl
3. Используйте это для улучшения базы

## 🔧 Технические детали

### Модули

- **models.py**: Dataclasses для предметов, модов, результатов
- **calculator.py**: Математические расчеты вероятностей
- **simulator.py**: Симуляция процесса рекомбинации
- **item_parser.py**: Парсинг предметов из текста игры (RU/EN)
- **gui.py**: Tkinter GUI с 5 вкладками и визуализацией

### Зависимости

- `tkinter`: Графический интерфейс (встроен в Python)
- `matplotlib`: Графики и визуализация

## 📊 Особенности реализации

1. **Импорт из игры**: Парсер распознает предметы в русском и английском формате
2. **Точные расчеты**: Формулы основаны на community research и testing
3. **Все механики**: Поддержка exclusivity, NNN mods, mod groups, fractured mods, influenced items
4. **Визуализация**: Графики распределения результатов
5. **Массовая симуляция**: До 100,000 попыток для точной статистики
6. **Встроенный гайд**: Полная документация по механикам прямо в приложении
7. **Удобный GUI**: Интуитивный интерфейс с 5 вкладками
