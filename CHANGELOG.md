# Changelog

## Version 1.3.0 - Полный Редизайн: Компактный Интерфейс (2025-11-05)

### 🎨 ГЛАВНОЕ: Новый компактный интерфейс в одном окне!

**Полностью переработанный UX/UI** - все функции в одном удобном окне!

#### Ключевые улучшения:
- ⚡ **Единое окно вместо 6 вкладок** - все перед глазами, никаких переключений
- 🎨 **Визуальные примеры** - графики вероятностей, прогресс-бары, цветовые индикаторы
- 💰 **Прозрачная экономика** - четкое отображение ресурсов и стоимости попыток
- 🚀 **Быстрый доступ** - импорт и создание предметов в два клика
- 📊 **Компактная информация** - только важное, без лишних деталей

#### Структура интерфейса:

**Левая панель (30%) - Предметы:**
- Быстрый импорт из игры (Ctrl+C → Вставить)
- Ручное добавление модов
- Визуальное отображение предметов
- Кнопка базовой рекомбинации

**Центральная панель (40%) - Стратегия:**
- Визуальный выбор желаемых модов
- Графическое отображение стратегии
- Пошаговый план действий
- Кнопка интеллектуального анализа

**Правая панель (30%) - Результаты:**
- Прогресс-бар вероятности
- Количество попыток
- Тип стратегии
- Детальный список ресурсов
- Оценка сложности с цветовым кодом

#### Новые файлы:
- `gui_new.py` (700+ строк) - новый компактный интерфейс
- Обновлен `main.py` - выбор интерфейса через флаги командной строки

#### Совместимость:
- Новый интерфейс запускается по умолчанию
- Старый интерфейс доступен через `python main.py --old`
- Все функции обоих интерфейсов сохранены

#### Технические улучшения:
- Оптимизирована компоновка для экранов 1600x900+
- Улучшена цветовая схема в стиле PoE
- Добавлены визуальные индикаторы (прогресс-бары, цветовое кодирование)
- Упрощен workflow для типичных сценариев

### 📊 Статистика

- **Новых файлов**: 1 (`gui_new.py`)
- **Обновлено**: `main.py`, `README.md`, `CHANGELOG.md`
- **Строк кода**: ~750 новых
- **Интерфейсов**: 2 (новый компактный + старый с вкладками)

## Version 1.2.0 - Интеллектуальный Помощник Крафта (2025-11-05)

### 🎯 ГЛАВНАЯ НОВИНКА: Помощник крафта

**Новая вкладка "🎯 Помощник крафта"** - интеллектуальный советник по крафту!

#### Возможности:
- **Визуальный выбор желаемых модов** - добавляйте префиксы и суффиксы через удобный интерфейс
- **Автоматическая валидация** - проверка возможности комбинации, обнаружение конфликтов
- **Интеллектуальный анализ** - определение оптимальной стратегии (базовая/exclusive/NNN)
- **Детальные рекомендации** - вероятность, попытки, пошаговый план, ресурсы, советы

#### Новые файлы:
- `craft_advisor.py` (400+ строк) - анализатор стратегий крафта
- `test_advisor.py` - интерактивные тесты
- `test_advisor_auto.py` - автоматические тесты (все ✓)

#### Примеры:
- 3 физ мода → Базовая рекомбинация, 31%, ~3 попытки
- 5 модов с essence → Exclusive стратегия, 15%, ~6 попыток
- 4 префикса → Невозможно (автоматическое предупреждение)

### 📊 Статистика

- **Новых файлов**: 3
- **Обновлено**: gui.py, README.md, CHANGELOG.md
- **Строк кода**: ~900
- **Вкладок**: 6 (было 5)
