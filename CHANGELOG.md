# Changelog

## Version 1.2.0 - Интеллектуальный Помощник Крафта (2025-11-05)

### 🎯 ГЛАВНАЯ НОВИНКА: Помощник крафта

**Новая вкладка "🎯 Помощник крафта"** - интеллектуальный советник по крафту!

#### Возможности:
- **Визуальный выбор желаемых модов** - добавляйте префиксы и суффиксы через удобный интерфейс
- **Автоматическая валидация** - проверка возможности комбинации, обнаружение конфликтов
- **Интеллектуальный анализ** - определение оптимальной стратегии (базовая/exclusive/NNN)
- **Детальные рекомендации** - вероятность, попытки, пошаговый план, ресурсы, советы

#### Новые файлы:
- `craft_advisor.py` (400+ строк) - анализатор стратегий крафта
- `test_advisor.py` - интерактивные тесты
- `test_advisor_auto.py` - автоматические тесты (все ✓)

#### Примеры:
- 3 физ мода → Базовая рекомбинация, 31%, ~3 попытки
- 5 модов с essence → Exclusive стратегия, 15%, ~6 попыток
- 4 префикса → Невозможно (автоматическое предупреждение)

### 📊 Статистика

- **Новых файлов**: 3
- **Обновлено**: gui.py, README.md, CHANGELOG.md
- **Строк кода**: ~900
- **Вкладок**: 6 (было 5)

## Version 1.1.0 - Импорт и Полный Гайд (2025-11-05)

### 🎉 Новые возможности

#### Импорт предметов из игры
- **Парсер предметов** (`item_parser.py`)
  - Поддержка русского и английского языка
  - Автоматическое определение класса предмета
  - Распознавание всех типов модов
  - Определение fractured модов
  - Оценка тиров на основе значений
  - Поддержка всех классов предметов (кольца, амулеты, оружие, доспехи и т.д.)

- **Диалог импорта в GUI**
  - Кнопка "Импорт из текста" на вкладке настройки
  - Удобный текстовый редактор для вставки
  - Автоматическое заполнение всех полей
  - Подтверждение с деталями импорта

#### Полный гайд по рекомбинаторам
- **Новая вкладка "Гайд"**
  - Основные правила рекомбинации
  - Таблицы вероятностей успеха
  - Формулы расчета (с точными значениями)
  - Эксклюзивные моды - механика и использование
  - NNN (Non-Native Natural) моды - техники применения
  - Продвинутые стратегии крафта
  - Практические примеры (оружие, доспехи)
  - Советы и предостережения
